Would any labelling of the halves do this?
The volcano alone cannot answer this. Any consistent way of naming which half is which produces some calls, so the whole analysis is re-run 200 times with each embryo's side assignment flipped at random, and the calls counted. The histogram is that null; the line is the real number. If the real number sits inside the histogram, the volcano is describing the labelling rather than the embryo.
Does the plane definition matter?
Figures 4.18 and 4.14. Median fold asymmetry over the genes every definition can test, with a bootstrap interval, plus the per-gene grid underneath. Read the random plane first — it is not at 1.0, because counting noise alone produces a fold, and everything else has to be judged against it. The best meridional plane is selected to be asymmetric, so its lead over random is partly the selection; it is shown next to random for exactly that reason.
Per gene, against a count-matched null
Figure 4.17. A gene with few transcripts looks asymmetric by sampling alone, so the null draws the same counts from the same half-volumes and what is plotted is the excess over it. A tall bar on a low-count gene is the failure mode this panel exists to prevent.
Do a zygote's two halves sit together?
Figure 4.15. Each zygote contributes two points, joined by a line. One panel per probeset, because the four panels are disjoint gene sets and a single embedding would cluster by which panel was run. The share view has a trap in it: under share features the two halves are exact complements — every feature in B is 1 minus the one in A — so any embedding pushes them apart and the pairing ratio comes out above 1. That is geometry, not biology. The concentration view is the one that answers the question; both are here so the artefact is visible rather than reported as a result.
